# CHANGE CONTROL v2

## Why
The biggest integration risk is an AI coding agent changing an interface to make its local task easier.

## Change request format
CR-ID:
Requester:
Module:
Current contract:
Proposed change:
Reason:
Affected modules:
Migration:
Tests:
Approval:

## Emergency rule
During the 24-hour event, avoid contract changes after hour 12.
If absolutely necessary, M5 coordinates all affected members.

## Forbidden
No agent may silently edit:
- API contracts
- canonical schemas
- model interface
- tool interface
- security boundary
